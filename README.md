# ペース予報

**https://ebiebimanman.github.io/pace-monitor/**

仕事中の「なんか集中できない」を予報する Web サイトです。睡眠・体調・時間帯・天気・換気や休憩の経過から、今日のどの時間に集中が落ちやすいか（ペースダウン時間）を出します。集中が切れたときは、原因と対処法を提案します。

集中できている時間は放っておきます。集中が落ちる時間をうまくやり過ごすためのものです。

- ログインもインストールもいりません。URL を開くだけで使えます
- 記録はすべて、使っているブラウザの中にだけ保存されます（詳しくは「データの扱い」）
- PC のブラウザで、タブを 1 日開いておく使い方を想定しています。スマホでも表示できます

## 使い方

### 1. 初回設定（最初の 1 回だけ）

5 つの質問に答えます。どれもスキップでき、あとから「設定」で変えられます。

| 項目 | 何に使うか |
|---|---|
| 仕事の時間 | グラフに出す時間帯と、通知を送る時間帯 |
| いつもの就寝・起床時刻 | 朝のチェックインの初期値。チェックインしなかった日の計算 |
| からだのこと | 生物学的な性別。女性を選ぶと、最終月経の開始日と周期を聞きます。月経中と月経前の数日はコンディションを低めに予報します |
| 場所 | その場所の気温・湿度・気圧・日差しを予報に使います |
| 通知 | ペースダウン時間の前などにお知らせします |

### 2. 朝のチェックイン（毎日 30 秒）

その日最初に開くと出てきます。寝た時刻・起きた時刻、睡眠の質、今の体調、冷暖房を答えると、今日のコンディション（%）を計算します。「あとで」を選ぶと、いつもの時刻で仮に計算します。

### 3. ホーム

- **今日のコンディション**：今日、力を出しやすい環境かを 0〜100% で表します。何で下がっているかの内訳も出ます
- **グラフ**：時間帯ごとのコンディションです。網かけの部分がペースダウン時間です。カーソルを合わせると、その時間に上がる・下がる理由が出ます
- **記録ボタン**：［窓開けた］［休憩する］［水飲んだ］［ご飯食べた］。押すと予報を計算し直します
  - ［休憩する］は 5・15・30・60 分から長さを選びます。休憩が終わった時刻から、休憩なしの時間を数え始めます
  - ［ご飯食べた］を押した日だけ、食後に眠くなりやすい時間を予報に入れます
  - あとから入れた記録は、グラフの下のアイコンを押すと時刻を直せます

### 4. 集中が切れたら

［集中切れた］を押して、今の症状（眠い、頭痛、MTG 後でぐったり など）を選びます。今の状況に合いそうな対処法を、効きそうな順に出します。試したい対処は［やってみる］を押してください。15 分後、ホームの「ふりかえり」で効いたかを聞きます。効いた対処は、次から上に出やすくなります。

### 通知について

通知は、**このページのタブを開いている間だけ**届きます。タブを閉じると届きません。ブラウザのタブを右クリックして「固定（ピン留め）」しておくと、閉じ忘れを防げます。

## データの扱い

- 設定・チェックイン・記録は、すべて使っているブラウザの localStorage に保存します。開発者を含め、外部のサーバーには送りません
- 外と通信するのは、天気の取得と場所の検索（[Open-Meteo](https://open-meteo.com/)）と、気温の実測の取得（[気象庁アメダス](https://www.jma.go.jp/bosai/map.html#contents=amedas)）だけです。Open-Meteo に送るのは、選んだ場所の緯度・経度と検索した地名だけです。アメダスには場所を送りません（観測点の一覧をまとめて取得し、最寄りの観測点はブラウザの中で選びます）
- 別のブラウザや別の PC とは記録を共有できません。ブラウザの閲覧データを消すと、記録も消えます
- 「設定」→「データ」から、記録を JSON でコピーしたり、すべて削除したりできます

## 注意

予報は、一般的な傾向をもとにした目安です。医学的な診断ではありません。体調の悪い日が続くときは、無理をしないでください。

## 開発者向け

### ローカルで動かす

Node.js 24 以上が必要です。

```sh
git clone https://github.com/ebiebimanman/pace-monitor.git
cd pace-monitor
npm install
npm run dev     # http://localhost:5173 で開く
npm test        # 計算ロジックと通知判定のテスト（狭山市 2026-10-01 のデータで検証）
npm run build   # dist/ に静的ファイルを出力
```

`main` ブランチに push すると、GitHub Actions がテストとビルドをして GitHub Pages に公開します（`.github/workflows/deploy.yml`）。

### 構成

| 項目 | 採用 |
|---|---|
| フレームワーク | Vite + React + TypeScript（静的 SPA） |
| データ | ブラウザの localStorage（ログインなし） |
| 天気・場所検索 | Open-Meteo（API キー不要、ブラウザから直接呼ぶ） |
| 気温の実測 | 気象庁アメダス（予報の気温を補正する） |
| テスト | Vitest |
| 公開 | GitHub Pages |

```
src/
  App.tsx        画面全体の組み立てと記録の更新
  components/    グラフ、パネル、モーダル（チェックイン・集中切れた・休憩・記録の編集・設定・初回設定）
  hooks/         保存（useStore）、天気（useWeather）、アメダス（useAmedas）、現在時刻、通知、1 画面レイアウト
src/lib/
  types.ts       データの型
  time.ts        時刻の変換・表示
  weather.ts     Open-Meteo の取得と補間
  amedas.ts      アメダスの最寄り観測点・最新の気温・予報の補正
  humidity.ts    推定室内湿度
  cycle.ts       月経周期
  condition.ts   今日のコンディション・曲線・ペースダウン区間
  causes.ts      「集中切れた」の対処候補
  storage.ts     localStorage
icons/           記録・カレンダーのアイコン
```

計算の式と画面の仕様は [docs/spec.md](docs/spec.md) にあります。カレンダー連携・ログイン・Web Push は v2 以降の予定です（仕様書の 8 章）。
